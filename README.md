CapsFlip - made by @0honzik

1. Put CapsFlip.exe in a folder you will keep (for example Documents\CapsFlip).
2. Run it. An "Aa" icon appears in the tray (click ^ next to the clock).

Caps Lock: select text and press Caps Lock.
   Not all caps  -> ALL CAPS
   All caps      -> Sentence case (or Title Case, see tray menu)
   Shift+Caps Lock, or nothing selected -> normal Caps Lock.

Right Ctrl lookup: select a word and tap Right Ctrl (just tap it, do not
press another key with it). Google opens with the meaning of the word.
Czech or English search can be chosen in the tray menu.

Right-click the tray icon for settings, including "Start with Windows".

Windows may warn about an unknown publisher because the app is not code-signed.
Click "More info" -> "Run anyway".
